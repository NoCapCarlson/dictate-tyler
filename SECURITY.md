# Security & Privacy

## Processing model

Dictate performs all speech recognition on-device. Audio is captured to
memory, transcribed locally by CTranslate2-based Whisper models, typed at
the active caret, and discarded. The application makes no network calls at
runtime, requires no account or API key, and collects no telemetry.

Persistent artifacts are limited to:

- `%LOCALAPPDATA%\carlson.log` — operational log (timestamps and error
  traces; never audio, never transcripts)
- the current transcript on the system clipboard, replaced per take
- recognition models cached under the user's Hugging Face model cache

## Input integrity

Dictate installs a low-level keyboard hook to implement its push-to-talk
trigger. The design guarantees that the trigger key can never be left in a
captured state: suppression is valid only while the key is physically held,
a watchdog releases it otherwise, and terminating the process restores
normal keyboard behavior instantly. A named mutex prevents concurrent
instances. Synthetic input generated by Dictate is ignored by its own hook.

Windows User Interface Privacy Isolation prevents Dictate (running
unelevated) from typing into elevated windows; this is expected behavior.

## Reporting

This is a private, single-user deployment. Concerns or defects: open an
issue in this repository.
